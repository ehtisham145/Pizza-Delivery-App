⭐ Reviews & Ratings — Full Deep Dive
________________________________________
🗄️ Database Model
Column	Type	Notes
id	Integer	
order_id	FK → Order	unique — one review per order
user_id	FK → User	
rating	Integer	1 to 5 only
comment	String	optional
created_at	DateTime	


📡 API Endpoints
Method	URL	Who	What
POST	/api/v1/reviews	Customer	Submit a review
GET	/api/v1/reviews/my-reviews	Customer	My review history
GET	/api/v1/reviews	Admin	All reviews
DELETE	/api/v1/reviews/{id}	Admin	Delete abusive review
GET	/api/v1/menu/pizzas/{id}/reviews	Public	Reviews for a pizza


⚙️ Business Logic Rules
•	Review is only allowed when order.status == delivered — check this before allowing submission
•	One review per order — enforce with unique constraint on order_id column
•	Validate that the order being reviewed belongs to the logged-in customer
•	Rating must be between 1 and 5 — validate in Pydantic with ge=1, le=5
•	Customers cannot edit or delete their own review after submission — keeps it honest
•	Only admin can delete reviews
•	When fetching pizza details, optionally include average rating calculated from all its order reviews
